# Modulation format recognition based on supervised learning and high-dimensional features [with MATLAB code]

Abstract: The popular direction of automatic modulation classification algorithms is to study how to develop feature extraction methods for further signal classification. This paper proposes a mapping algorithm for artificially designed feature extraction methods using the reconstructed components of Principal Component Analysis (PCA), which further extracts discriminative features between signals through PCA reconstructed components. In response to the limitations of learning matrices in modulation signal classification, two supervised neural network models were studied. Some experimental results show that feature extraction using matrix mapping can distinctly differentiate different modulation methods. Moreover, the accuracy of modulation classification based on feature extraction via mapping slightly improves compared to some tri-directional deep learning methods, requiring lower training SNR requirements.
Introduction: The basic concept of automatic modulation classification (AMC) is identifying unknown modulation types from recognized radio signals, which serves as the foundation for subsequent signal preprocessing [1]. AMC represents an important part of many modern communication systems, such as radio cognitive systems and wireless spectrum perception [2]. Blind modulation recognition of received modulation signals is also an important challenge in commercial radio systems [3]. Without information about the transmitted signal and receiver parameters (such as carrier frequency and channel fading effects), blind modulation methods are challenging. These classification techniques can be used in intelligent receiver applications to improve transmission performance by selecting appropriate modifications compatible with the channel noise pattern [4]. The basic block diagram of AMC is shown in Figure 1. The AMC configuration includes a preprocessing section and a classification algorithm, which de-modulates the signal based on the detected modulation mode [1].
In recent years, multi-level modulation methods such as 64QAM, 256QAM, 32APSK, and APSK have been widely used in communication systems due to their high data rate transmission capabilities.
Due to the narrow distances between points in the constellation diagram, it is more challenging to classify high-order M-QAM (M≤8) and MAPSK compared to MQAM and MAPSK classification. Additionally, training neural network classification algorithms requires a larger input dataset, which increases computational complexity and degrades classification performance. To address these limitations, we believe that using Reconstructed Principal Component Analysis (PCA) and neural network classification algorithms to optimize machine learning matrices is crucial. Moreover, this enhancement in the network topology will provide more stable results than traditional deep learning network structures.
Deep learning is a subfield of machine learning that uses large amounts of data as training inputs and processes through multiple layers of distributed networks at each hidden node. Finally, an output classifier is provided by one layer. Literature review indicates that despite selecting appropriate network models, supervising network models have great potential for classification performance, but they have not received sufficient attention, limited to AMC. Furthermore, compared to extensive research on the performance of neural network classifiers in modulation classification (e.g., [6,7]), very few studies integrate feature matrix enhancement with neural network classifiers. Therefore, in our work, we studied the performance of two neural network architectures and evaluated their performance: (1) MLP neural network and (2) RBF neural network (RBFN). The related work typically involves two different approaches to AMC: likelihood-based (LB) and feature-based (FB). In the LB approach, AMC is considered as a hypothesis testing problem where the probability density function of the received signal is computed and classified by comparing the likelihood function with a predefined threshold. Although they are easy to implement, their strict assumptions about modulation patterns are not always accurate. Other measurements associated with LBAMC are described in [14]. Therefore, the FB method was adopted, which employs the concept of pattern recognition (PR) to formulate the AMC task and requires skilled feature extraction and classifier selection. They do not require computational complexity, hence they are used in recent proposed AMC algorithms. Additionally, accurate classification can be achieved by carefully selecting features and classifiers [15]. In [12], statistical features are extracted from signals to explore the AMC problem. Similarly, multiple cumulant orders are combined into a cumulant vector, and then the cumulant vector is used to distinguish the modulated signals from multiple transmitters. In these studies, the authors propose using multi-cumulant component vectors to improve the classification accuracy of single-cumulant vector classifiers. In [17], cyclic wavelet features were introduced to distinguish binary modulated signals. Moreover, more reliable classification accuracy was obtained at lower Signal-to-Noise Ratio (SNR) when Continuous Wavelet Transform (CWT) was used as an engineering feature for template matching classification methods [18].
Principal Component Analysis (PCA) is a useful method in statistical signal processing [19]. It can be used to minimize the dimensionality of the feature matrix for purposes such as data compression, PR, and data separation. PCA has also been developed to map raw feature vectors [20] and reduce the dimensionality of the feature vectors, providing additional support for solving signal classification problems by creating alternative sets of fewer variables. This allows the dataset to be represented by a smaller set of variables [21].

This work expands and consolidates [33] by proposing an in-depth study that highlights several points not considered before:
1. Reconstructed components can accurately interpret extracted features and form square input to capture more significant structural features in two-dimensional matrices.
2. Considered the most effective signal features and included a set of HOC and five features suggested by [34]. Special and instantaneous features are enhanced by natural logarithmic features (such as [35], spectral features, and two types of transformer features [18, 36]).
3. Used the reconstruction method of principal component analysis to reduce the number of feature bases and optimize the original features. Moreover, the reconstructed component optimizer can determine the maximum fitting parameters and the best feature subset for the classifier.
4. Experiments were conducted on ten modulation schemes including MPSK, MAPSK, MQAM, etc., with different channel degradation methods applied to degrade the signal quality. The results show that compared to similar classifiers, our proposed classifier achieves consistent classification accuracy.
This paper is not about introducing a classification technology with higher classification accuracy than other existing technologies. Instead, our goal is to develop a method to better adapt to existing classification methods without requiring additional packages for neural network structures, which will form a hybrid classifier by using PCA as the main block of the neural network structure.
